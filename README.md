# DM-Handbuch 5e

Nachschlagewerk für Dungeon Masters nach den D&D-5e-Regeln von 2024 (SRD 5.2), auf Deutsch mit englischen Begriffen.

Einfach `index.html` im Browser öffnen. Enthält:

- Charakterbogen: Attribute, Modifikatoren, Begriffe, Würfelbecher
- Würfe & Proben: welcher Wurf wann, Schwierigkeitsgrade, Vorteil/Nachteil, Fertigkeiten
- Kampf: Ablauf, Aktionen, Schaden, Monsterangriffe mit Angriffswürfler
- Zustände
- Rast, Magie & Welt
- Begegnungsrechner
- Charaktere: Übersicht und Details zur Gruppe
- NPC-Generator mit optionalen Kampfwerten

Regelzusammenfassung nach dem System Reference Document 5.2 (CC-BY-4.0, Wizards of the Coast), eigene Formulierung.
